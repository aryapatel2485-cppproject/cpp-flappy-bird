
# Flappy Bird Clone (C++ / SDL)

## About
This is a simple Flappy Bird–style game written in C++ using SDL.
I created this project as a school assignment to learn how basic
games work internally.

## Features
- Gravity-based bird movement
- Keyboard input (Space to jump)
- Moving pipe obstacles
- Collision detection
- Score and life system

## Controls
- Space: Jump
- Escape: Quit the game

## Requirements
- C++ compiler
- SDL library
- SDL_Wrapper (provided by school)

## How to Run
This project must be compiled and run locally with SDL installed.
It will not run in online compilers such as OnlineGDB or Replit.

## Why I Made This
I built this project to understand game loops, collision detection,
and basic physics in C++.
